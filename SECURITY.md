# Security Policy

## Project Status

NovaPay Risk Dashboard is a portfolio-based GRC and information security risk-management project. It is not a production payment-processing environment and does not process real customer, payment, or financial data.

The project uses simulated risk scenarios, control assessments, and governance data for demonstration and learning purposes.

## Supported Scope

Security considerations and updates apply to:

* Risk-register data and supporting project files
* Power BI dashboard artifacts
* GRC documentation
* Risk assessment methodology
* Framework mappings documented within the repository
* Supporting scripts or configuration files, where applicable

There are currently no production versions of this project that receive security patches.

## Reporting a Vulnerability

If you identify a security issue in the repository, dashboard, documentation, or supporting project files, please report it privately rather than publishing sensitive details in a public issue.

When reporting an issue, provide:

* A clear description of the issue
* The affected file, component, or feature
* Steps required to reproduce the issue, where applicable
* Potential security or data-protection impact
* Any suggested mitigation, if known

For issues involving exposed credentials, API keys, access tokens, personal information, or other sensitive information, do not include the sensitive value in a public issue.

## Response Process

Security reports will be reviewed based on their potential impact and relevance to the project.

Where appropriate, the project owner will:

1. Acknowledge receipt of the report.
2. Validate and assess the reported issue.
3. Determine whether remediation is required.
4. Document the risk and recommended treatment.
5. Implement or propose remediation where applicable.
6. Close the issue once the risk has been addressed or otherwise documented.

Because this is a portfolio project rather than a production service, response and remediation timelines may vary depending on the nature and severity of the issue.

## Scope Limitations

This repository does not represent a live NovaPay production environment.

The project does not contain:

* Real customer data
* Real payment-card data
* Production credentials
* Production API keys
* Live authentication secrets
* Confidential third-party information

Any examples of risks, vendors, controls, transactions, or security events are simulated for educational and portfolio purposes.

## Responsible Disclosure

Please allow reasonable time for review and remediation before publicly disclosing details of a security issue.

Thank you for helping improve the security and quality of the project.
